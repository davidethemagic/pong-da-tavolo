# Pong da tavolo

Pong contro il computer, in un solo file HTML.

## Come si gioca

Tu a sinistra, il computer a destra. Vince chi arriva a 7 con almeno 2 punti di scarto. Tre livelli di difficoltà.\n\nMouse o dito per muovere la racchetta, oppure W/S e frecce. Spazio per la pausa, M per l'audio.

## Provarlo

È un solo file, `index.html`: scaricalo e aprilo nel browser. Non serve installare niente e non si connette a nessun server (usa solo i caratteri di Google Fonts).
